# ifseen add-on

Plain-English triggers for your cameras. Write rules like "a parcel has been left on the
doorstep" and get a Home Assistant device with a binary sensor, probability sensor, trigger
event and snapshot camera for each rules file, over MQTT.

![Supports aarch64][aarch64-shield] ![Supports amd64][amd64-shield]

See the **Documentation** tab, or [docs/homeassistant.md][guide] for the full guide.
