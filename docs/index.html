01. How it works

One frame. One call.
Every rule.

Decision models don't write text. They read an image or audio clip and return a calibrated probability for each yes/no question, with zero output tokens. ifseen is the glue around them.

  1. 01 / CAPTURE

    Grab a frame

    Screen, webcam, RTSP, snapshot URL, file, and/or the last few seconds of mic audio.

  2. 02 / SKIP

    Unchanged? Skip

    Static frames and silence never hit the API. A quiet scene costs almost nothing.

  3. 03 / ONE CALL

    Ask all rules

    3 rules or 300, it's one request per frame. The image is billed once.

  4. 04 / DEBOUNCE

    Stay calm

    Thresholds, for: N consecutive hits, cooldowns and hysteresis. One alert per event.

  5. 05 / ACTION

    Do the thing

    Notify, speak, run a shell command, hit a webhook, push a photo to your phone, save the frame, exit.

      No training.
      No bounding boxes.

      Plain-English rules

      Ask what you'd ask a person.

      "The 3D print has turned into spaghetti." "The pot is boiling over." Use false_means to rule out look-alikes.

      ifseen.yaml
      source: screen
every: 3s
rules:
  - name: build-failed
    when: A CI pipeline on screen has failed.
    threshold: 0.85
    for: 2
    then:
      - notify: "Build failed ({percent})"
      - say: build failed
      Debounced & calm

      One alert per event. Not one every two seconds.

      A rule must clear its threshold for: N frames in a row, then waits out its cooldown and re-arms only when the probability drops.

      03. Providers

      Bring any
      decision model.

      With no provider set, ifseen picks the first one it finds a key for. --dry-run uses the mock provider, so you can try everything with no key at all.

      Supported providers, their environment variables and whether they can see and hear
      ProviderEnv / configSeesHearsNotes
      geminiGEMINI_API_KEY✓✓Gemini Decision 1. Free tier; $0.10 / 1M input tokens. live-tested
      jevTYPESAFE_API_KEY✓TypeSafe Jev 1.13+; $0.042 / 1M input tokens.
      azureAZURE_DECISION_ENDPOINT / _KEY / _DEPLOYMENT✓Microsoft-Decision-1.1 on Azure Foundry.
      systemonebase_url (+ TYPESAFE_API_KEY)✓Any self-hosted Jev-compatible /v1/systemone server.
      openaiOPENAI_API_KEY (+ OPENAI_BASE_URL)✓Any OpenAI-compatible vision chat model. Not calibrated, slower.
      ollamamodel✓Fully local, e.g. --provider ollama --model gemma3. offline
      mocknone✓✓What --dry-run uses: random probabilities, actions printed not run.
      localpip install "ifseen[local]"✓Free & offline: SigLIP on your machine, ~20ms, $0. Great for “is X there?” and as a prefilter. free
      PrivacyFrames and audio go to the provider you choose and nowhere else. Use Ollama or a self-hosted server and nothing leaves your machine.
      Not yet benchmarkedJev and Microsoft-Decision are supported but haven't been live-tested here yet, so there are no numbers for them on this page.
      Proxies & custom keysbase_url and api_key_env work for proxies, gateways and self-hosted servers.
